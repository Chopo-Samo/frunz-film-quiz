# Школьная видео-викторина

Готовый статический сайт-викторина: сначала воспроизводится короткое MP4-видео, затем появляются вопрос и 4 варианта ответа (`1`, `2`, `3`, `4`), а после выбора сразу подсвечивается правильный ответ.

## Как быстро загрузить сайт в интернет

### Вариант 1: Netlify Drop (самый простой, за 30 секунд)
1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите всю папку проекта `school-video-quiz` в окно браузера.
3. Через несколько секунд вы получите готовую ссылку вида `https://имя-сайта.netlify.app` — её можно сразу открывать в школе.

### Вариант 2: GitHub Pages
1. Создайте новый репозиторий на GitHub и загрузите туда все файлы из папки проекта (вместе с папкой `videos/`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment → Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по ссылке `https://ваш-логин.github.io/название-репозитория/`.

## Как менять вопросы и видео
Откройте файл `quiz-data.js` в любом текстовом редакторе и измените массив `questions`:
- `video`: путь к вашему файлу (например, `"./videos/clip1.mp4"`).
- `question`: текст вопроса.
- `options`: 4 варианта ответа.
- `correct`: номер правильного варианта (`1`, `2`, `3` или `4`).
- `explanation`: короткий комментарий, который появится после ответа (можно оставить пустым `""`).
